# Retail Business Analytics | Power BI

## Project Overview
This project presents a Power BI dashboard designed to explore retail business performance through sales, profit, and demographic analysis.

## Dashboard Pages
- **Sales Analysis:** Explore sales performance and trends.
- **Profit Analysis:** Analyze profit-related performance.
- **Demographic Analysis:** Explore demographic data using visualizations.

## Tools & Technologies

- Power Query
- Data Visualization
- Business Intelligence
